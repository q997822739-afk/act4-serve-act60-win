GM 命令一览

--- 开关 / 等级 / 转职 / 技能 ---------------------------------------------------------------

#ehdgusrlwn                         	开启GM命令,再次输入#ehdgusrlwn关闭12
#realmode                              	关闭GM模式（等价于再敲一次 #ehdgusrlwn）
#level up                              		升一级
#level down                             	降一级
#levelto 60                             	升级（直接跳到指定等级，范围 1..60）
#grow 1 3                               	转职：第一个参数固定填 1（ACT5 只有一转），第二个是职业编号 0..5转完会按新分支重建技能表并按等级重算 SP
#clear all skill                        	技能初始化：清空全部技能，SP 按当前等级重算
#add skill 100 5                        	把某个技能设到指定等级（技能号 + 等级）

--- 物品 / 金钱 ------------------------------------------------------------------------------

#add item 3171 10                       获取对应数量的物品（数量必填；可堆叠的会被截到堆叠上限；时装请用 #add avatar）
#add avatar 12345 1 30 0                发时装：物品号 + 部位 + 期限(天) + 颜色；期限填 0 或 99 = 用物品自带期限
#money 10000000                         设金币（是「设成这个数」不是增加；填 0 什么都不做）
#coin 1                                 		扣复活币（🔴 是扣不是加；填 0 或负数什么都不做）
#enchant 0 5 12345                      直接写一件物品的 enchant 字段：容器号 + 槽号 + 值
                                        		容器号：0=背包 1=装扮栏 2=金库 3=已穿戴 4=交易栏 7=宠物 12=账号金库
#addinfo 0 9 23207                      直接写一件物品的 add_info 字段（Inven_Item+7）：容器号 + 槽号 + 值
#cinven                                 清空整个背包
#dirty avatar                           清空整个装扮栏

--- 强化 ------------------------------------------------------------------------------------

#upgrade success|fail|random            开启强化对应的状态
#upgrade success                        下一次强化必成
#upgrade fail                           下一次强化必败
#upgrade random                         强化恢复随机

--- 账号 / 管理 ------------------------------------------------------------------------------

#mid 角色名                             查一个角色属于哪个账号（答案走 NOTI 138；名字超过 29 字节时官方这一支不发包）
#kick 角色名                            把某个在线角色踢下线（不能踢自己）
#setgm add 10000                        把一个账号加进 gm_manifest（参数是账号编号不是角色名；⚠ 别的频道进程要重启才认）
#setgm remove 10000                     从 gm_manifest 里撤销一个账号的 GM 资格

    🔴 在 gm_manifest 里的账号，进游戏之后【名字上带运营者标记】：名字染成淡蓝
       （普通玩家是灰白），旁边画一个 Temp/AdminIcon.img 的圆形图标。同区域的其他
       玩家也看得见 —— 走的是 NOTI 2 子类型 0 的 #10，那是世界级广播的同一条记录。
       ⚠ 它和【公会徽章】是二选一：客户端那段是 if/else，GM 身上的公会徽章会被顶掉。
       ⚠ 门槛是「在不在名单里」，不是「开没开 GM 模式」—— #ehdgusrlwn 只管命令权限。
       ⚠ #setgm add 是给【别的账号】加的，那个账号要重新选角进游戏才会看到标记
         （身份包是在选角之后那一刻拼的）。

任务（两条，做的是两件不同的事，别混）

#questdone               让【进行中】的任务立刻可以交，然后你自己去任务书里点「完成」——
                         材料、奖励、经验、后续任务的解锁，全套照常走一遍。
                         不带参数 = 所有进行中的任务；#questdone 105 = 只弄那一个。
                         别名 #questclear2 / #q（官方那条文本命令自己就是这两个名字）。
                         🔴 材料也免了，但【只免这一次】：照官方，交完一次任务免检就自动关，
                            要连交第二个任务就再敲一次。
                         🔴 进度本来就满、只差材料的那种，敲了它直接点完成就行。

#clearquest 100 101 102  把这几个任务【直接标成已通关】，不发奖励、不看进不进行中。
#clearquest all          这个角色现在够得着的任务全标完成。
                         用来跳过一整条前置任务链去测后面的内容。
                         🔴 客户端的已完成表【只在选角时收】，靠前置任务开门的副本
                            （比如暗黑雷鸣废墟要 203 号任务）得【重选一次角色】才出现。
                         ⚠ 照官方保留了那道闸：职业、等级上下界、转职分支对不上的会被跳过
                            （前置任务链不在这道闸里，所以 all 一遍就能推平整棵树）。
                         ⚠ 照官方：碰到 quest.lst 里查不到的号会【整批中断】，
                            它后面的号一个都不处理 —— 回话里会点名是在哪个号上断的。

副职业（附魔师）
#expertjob type 1        转成附魔师（官方 CChangeExpertJobCmd）。ACT5 只上了附魔师 = 1
#expertjob type 0        卸职。⚠ 照官方那一支：技能不收回、配方不清、次数不加、不收费
                         —— 玩家走的正规放弃是副职业窗口里那个按钮（CMD 258），两回事
#expertjob 1000          把熟练度【设成】1000（官方 CMD 65 子命令 0x1B）
                         ⚠ 名字叫 Increase 语义是 Set，而且落下去的值多半小于你敲的：
                           ACT5 的 expertjob.etc 缺 [expertjob level limit]，
                           官方那道钳位让它【一次最多升一级】。要升满就连着敲几次。
                           回话里报的是真正落下去的值。
#learnrecipe all         一次学完 31 张配方（🔴 官方没有这一条，是本项目的测试工具）
#learnrecipe 2604001     学一张，参数是配方的物品编号（不是位图序号）
